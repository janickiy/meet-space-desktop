# MeetSpace 0.2.0 beta

В настройках профиля можно выбрать фото, увидеть предпросмотр, сохранить или удалить аватарку. Сохранённое фото отображается в профиле, карточке аккаунта и боковой панели Windows и Linux.

PNG, JPEG и WebP до 10 МБ обрезаются по центру и уменьшаются до квадратного JPEG не более 512×512. Фото передаётся только после нажатия «Сохранить фото», через авторизованное подключение к выбранному серверу. Сервер хранит аватар профиля; после удаления возвращаются инициалы. Требуется сервер с API аватаров профиля.

Проверки: ограничения и авторизация транспорта, загрузка и удаление через настоящий React/Electron интерфейс с локальным TLS-сервером, предпросмотр без загрузки, уменьшение изображения, обновление боковой панели, сохранение при переходе между разделами и отклонение SVG. Сборки Windows x64/ARM64 и Linux DEB/RPM/AppImage x64/ARM64 имеют контрольные суммы и сведения об исходниках.

Пакеты внутренней beta не подписаны. Проверка установленного приложения выполняется на ARM64 в UTM; запуск x64 на отдельной физической системе в этот выпуск не входит.
