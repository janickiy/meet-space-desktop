# MeetSpace 0.2.2 beta

Обновление общего Desktop для Windows и Linux включает расширенную поддержку архивов и документов во вложениях, актуальные изменения медиоустройств, системной интеграции и интерфейса. Публикуемые форматы: Windows EXE и Linux DEB/RPM/AppImage для x64 и ARM64. Пакеты macOS в эту публикацию не входят; общие исходники содержат платформенные ветки macOS, необходимые для единого проекта.

## Исходники сборки

Пакеты собираются из зафиксированного набора **527 файлов** с SHA-256 `313d2c331c8934df7872098138c825f3f3b9a018a48e9ba20be3878e240936a0`. Базовый commit — `88107709dd896a8839cd1ac59bee649240a18ae6`; рабочее дерево во время сборки было dirty. Поэтому один базовый commit не идентифицирует содержимое пакетов: точные входные файлы перечислены в [манифесте](0.2.2-beta-source-inputs.json). Commit публикации исходников создаётся после сборки и не подменяет записанное в ней происхождение.

## Выполненные проверки

- Desktop unit: **414 PASS, 0 FAIL, 1 SKIP** из 415. Единственный пропуск — настоящий GIO Desktop Entry launch, недоступный на Darwin.
- Frontend: **30 foundation + 55 media + 9 assets PASS**.
- Desktop и Frontend TypeScript, общая сборка: **PASS**.
- React/Electron product UI: **17 групп PASS** — отправка сообщений, очередь при потере сети и повторная отправка без дубликатов, архивы и документы через настоящий frontend и локальный TLS API, аватар, папки, календарь, записи и настройки.

Проверки выполнены в изолированной копии на Darwin ARM64, Node 24.19.0 и Electron 44.9.3; до и после них SHA-256 исходников совпадает. [Сводка](0.2.2-beta-verification.json), [результат product UI](0.2.2-beta-product-ui.json).

Это проверки общего кода и интерфейса с временным профилем и локальными fixtures. Они не заменяют нативную приёмку Windows/Linux, физические устройства или системные диалоги воспроизведения и сохранения. Установка в пользовательские VM UTM в эти проверки не входит.

Пакеты внутренней beta не подписаны; автоматические обновления отключены. Факт публикации пакетов и проверка ссылок лендинга фиксируются отдельно после доставки.
