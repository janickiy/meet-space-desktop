# MeetSpace Desktop 0.5.0

Обновлены рабочее пространство, встречи, календарь, библиотека записей, папки, настройки и мастер подключения к серверу. Библиотека записей поддерживает вкладки «Завершённые» и «В эфире», поиск, фильтры и сортировку. Карточки папок показывают первые два доступных элемента.

В личном, групповом и конференционном чате можно выделить несколько комментариев и переслать их вместе с вложениями. «Удалить у меня» скрывает выбранное на текущем устройстве для вошедшего аккаунта. «Удалить для всех» учитывает права на сервере.

Для Windows доступны установщики EXE, для Linux — пакеты DEB, RPM и AppImage. Для каждого формата есть варианты x64 и ARM64. Это тестовые сборки без цифровой подписи. [Пакеты и контрольные суммы](../../source/README.md).

Все восемь файлов собраны из коммита `9290b6ca09f119b282344ac800a679adea9ef5d0`. Пройдены 22 функциональных сценария Electron. Интерфейс проверен в светлой и тёмной темах, включая 18 комбинаций ширины окна и масштаба. Установка RPM поверх 0.4.0 проверена на Fedora 44 для обеих архитектур. [Манифест сборок](0.5.0-packages.json).
