# MeetSpace 0.3.1 beta

Исправлена вёрстка сообщения «Не удалось проверить сессию»: адрес сервера вынесен в отдельную строку, кнопки повторной попытки и выхода выровнены и разделены отступами. На узком окне действия располагаются вертикально; длинный адрес сервера переносится без обрезки.

Правка общая для Windows и Linux. Настройки аудио, видео и уведомлений из 0.3.0 beta сохранены.

Проверки: сборка TypeScript/React/Electron; 416 тестов Desktop пройдены, один платформенный тест пропущен. Общий интерфейс проверен в Electron с локальными HTTPS-серверами: восстановление сессии при недоступном сервере, выбор другого сервера, изоляция аккаунтов. Карточка проверена при ширине 360, 768 и 1280 пикселей в светлой и тёмной темах, с длинным доменом и масштабом текста 125%.

Собраны восемь тестовых пакетов: Windows NSIS и Linux DEB/RPM/AppImage для x64 и ARM64. Встроенные файлы и архитектуры проверены; все пакеты привязаны к одному чистому снимку исходников. Пакеты без цифровой подписи, автоматические обновления отключены. Установка этого выпуска в UTM не входит в текущую публикацию; проверки пакетов не заменяют приёмку на каждой целевой ОС.

Пакеты macOS на странице загрузки сохраняются на версии 0.2.3 beta. Предыдущие выпуски Windows/Linux в репозитории сохранены. [Пакеты и исходники](0.3.1-beta-packages.json) · [Проверка публикации](0.3.1-beta-publication.json).
