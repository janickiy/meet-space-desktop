# MeetSpace Desktop 0.2.3 beta

Редактор фото профиля и группы по макету: карточки фото, подтверждение удаления, круглая обрезка, перетаскивание, масштаб, смещения, сброс, предпросмотр, замена, сохранение и отмена. Ошибка загрузки сохраняет выбранную область для повторной попытки.

Пакеты Windows EXE, Linux DEB/RPM/AppImage и macOS DMG для x64 и ARM64 используют общий React-интерфейс. Тестовые сборки без публичной подписи; macOS DMG без Developer ID и нотариализации. Автообновление выключено. Проверки архива пакета не заменяют приёмку на каждой ОС.

Редактор проверен в Electron на macOS ARM64: профиль и группа, отмена, смена фото, кадрирование, ошибки загрузки и повторное сохранение, удаление, светлая/тёмная темы и узкое окно. Новые пакеты не устанавливаются в пользовательские системы автоматически.
