# MeetSpace Desktop 0.1.14 beta

Предварительный выпуск Windows и Linux от 27 октября 2026 года.

## Изменения

- В меню завершённых и отменённых встреч оставлены только «Информация о чате» и «Покинуть чат». Настройки уведомлений при открытии этого меню больше не запрашиваются.
- Правая граница панели настроек на широком экране выровнена с карточкой активного аккаунта во всех вкладках.
- Ярлыки Windows на рабочем столе и в меню «Пуск» называются MeetSpace.

## Проверка и ограничения

Общий интерфейс используется в Windows и Linux. Пакеты собраны из одного зафиксированного состояния исходников; сведения о сборках и контрольные суммы находятся в каталоге source.

Это тестовый выпуск без цифровой подписи приложения. Автообновления отключены. Полная проверка всех целевых ОС и оборудования не завершена. Ограничения аудита перечислены в [отчёте](../desktop-audit/DESKTOP_TEST_REPORT.md).
