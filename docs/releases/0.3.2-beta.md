# MeetSpace 0.3.2 beta

Во вкладке «Аудио» карточки микрофона, динамика и звуков вызовов/уведомлений выровнены в один ряд на широком окне. Колонки имеют одинаковую ширину; на узком окне карточки располагаются вертикально. Во вкладке «Уведомления» настройки событий и Email используют такие же переключатели, как остальные разделы: подписи слева, переключатели справа, одинаковые интервалы.

Изменения общие для Windows, Linux и macOS. В этом выпуске опубликованы восемь пакетов Windows/Linux: Windows EXE и Linux DEB/RPM/AppImage, для x64 и ARM64. Публикация macOS сохранена.

Проверки: TypeScript/React/Electron; 416 тестов Desktop пройдены, один платформенный тест пропущен. Общий интерфейс проверен в Electron в светлой и тёмной темах при ширине 1024, 1440, 1662 и 1920 пикселей и масштабе текста 100%/125%. Проверены одинаковые размеры аудиокарточек, отсутствие обрезанных элементов, выравнивание переключателей, управление клавишей Space и сохранение параметров уведомлений.

Все восемь пакетов проверены по содержимому, архитектуре, размеру, SHA-256 и SHA-512. Исходники: чистый commit `9f129f1c2675dddd4bac0d64af06c57f71aeaf4a`, SHA-256 набора из 534 файлов `547fac11ab9b1f7912d39c5fe91ee0257a6182cdc27b67a455d623a1940694d4`. Пакеты тестовые, без цифровой подписи; автоматическое обновление отключено.

В UTM обновлены и запущены Windows 11 ARM64 и Ubuntu ARM64. Проверены версия и контрольные суммы установленных файлов, сохранены аккаунты и настройки. В Windows ярлыки называются MeetSpace; в Ubuntu приложение закреплено в боковом меню, ограничение AppArmor сохранено. Визуальная проверка в UTM в этом прогоне недоступна: API снимка экрана не возвращал изображение. Это не заменяет проверку на физических x64-машинах.
