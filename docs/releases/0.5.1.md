# MeetSpace Desktop 0.5.1

В разделе «Настройки → Аккаунты» обновлены список аккаунтов и форма добавления. В форме доступны вход в существующий аккаунт и регистрация нового. Адрес текущего сервера отображается в форме. Его можно сменить в разделе «Подключение».

Выпуск включает установщики Windows EXE и пакеты Linux DEB, RPM и AppImage для x64 и ARM64. Это тестовые сборки без цифровой подписи. [Манифест сборок](0.5.1-packages.json) · [Контрольные суммы](../../source/releases/0.5.1/SHA256SUMS) · [GitHub Releases](https://github.com/janickiy/meet-space-desktop/releases/tag/0.5.1).

Вход вторым аккаунтом и создание аккаунта проверены на тестовом сервере. Обновление установлено в Windows 11 ARM64 и Ubuntu 24.04 ARM64 в UTM. В Windows проверены оба режима формы. В Ubuntu проверены запуск и экран входа.
