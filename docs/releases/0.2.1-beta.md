# MeetSpace 0.2.1 beta

Значок отправки выровнен по центру кнопки в чатах Windows и Linux.

При потере соединения отправляемое сообщение остаётся в переписке с восклицательным знаком рядом. Отдельный блок ошибки отправки больше не появляется. Нажатие на значок повторяет отправку с тем же идентификатором: потерянный ответ сервера не приводит к созданию дубликата. Несколько неотправленных сообщений не заменяют друг друга и сохраняются при переходе между чатами в текущей сессии приложения. Очередь разделена по серверу, аккаунту и переписке и очищается при выходе из аккаунта. Загруженная история остаётся видимой при сетевом сбое фонового обновления.

Сохранены функции версии 0.2.0, включая редактирование аватарки в настройках профиля.

Проверки: настоящий интерфейс React/Electron и локальный TLS-сервер — потеря соединения, несколько неотправленных сообщений, отсутствие отдельного сообщения об ошибке, повторная отправка, потерянный ответ сервера, защита от дубликатов и геометрия значка отправки. Пакеты Windows EXE и Linux DEB/RPM/AppImage собраны для x64 и ARM64 с контрольными суммами и сведениями об исходниках.

Пакеты внутренней beta не подписаны; автоматические обновления отключены. Проверки упаковки x64 не заменяют приёмку на отдельной x64-системе. Установка в пользовательские VM UTM не входит в этот выпуск.
