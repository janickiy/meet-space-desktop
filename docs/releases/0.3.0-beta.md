# MeetSpace 0.3.0 beta

Настройки «Аудио», «Видео» и «Уведомления» приведены к составу параметров макета janickiy/decs_maket (7248a87).

- Аудио: отдельные карточки микрофона, динамиков, звонков и уведомлений; выбор устройств, проверки звука и независимые уровни громкости. Уровень микрофона применяется к исходящему звуку в звонке. Сохранены шумоподавление и вход с выключенным микрофоном.
- Видео: предпросмотр с включением камеры, выбор устройства, вход с выключенной камерой, собственное видео и скрытие видео участников.
- Уведомления: приглашения, напоминания, готовность записи, звук и доставка по email. Настройки сервера сохраняются кнопкой; локальные параметры звука сохраняются автоматически. Ранее сохранённые скрытые параметры push и итогов встречи не перезаписываются.

Выбор устройств и громкость разделены по серверу и аккаунту. Переключение вкладок останавливает тестовую камеру и микрофон. Установщик сервера не менялся.

Проверки: сборка TypeScript/React/Electron; 414 модульных тестов Desktop (один платформенный пропуск); 56 сценариев жизненного цикла медиа; интерфейс с локальным HTTPS-сервером, сохранение параметров и светлая/тёмная темы при ширине 1024 и 1440; настоящий WebRTC-тест громкости микрофона (100%, 25%, 0%) и освобождения 27 AudioContext; двухсторонний SFU-звонок с прямым соединением и через TURN.

Выпускаются Windows NSIS и Linux DEB/RPM/AppImage для x64 и ARM64. Пакеты macOS 0.2.3 beta не изменялись. Тестовые пакеты без цифровой подписи, автоматические обновления отключены. Проверки x64-пакетов не заменяют приёмку на отдельном x64-компьютере.

Установлены и запущены сборки ARM64 в Ubuntu 24.04 и Windows 11 в UTM. Версия и SHA-256 установленного приложения совпадают с пакетами; аккаунты и настройки сохранены. Ярлыки Windows называются MeetSpace, приложение закреплено в Dock Ubuntu. Визуальная проверка в UTM не завершена: Mac был заблокирован. Интерфейс настроек проверен отдельно в автоматизированном запуске Electron.

Восемь пакетов опубликованы в репозитории и на странице [загрузок](https://meet-space.janickiy.com/download). Каждый публичный файл повторно скачан и проверен по SHA-256 и размеру. Проверены переключатели архитектуры/дистрибутива на лендинге при ширине 1440 и 390 пикселей; macOS и Android не изменялись.
