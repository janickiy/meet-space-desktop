# MeetSpace 0.3.3 beta

Кнопки ответа и отклонения личного звонка приведены к стилю микрофона и камеры: одинаковые размеры и скругления, иконка внутри, подпись снизу. Зелёный и красный цвета действий сохранены. Из раздела «Записи встреч» удалены счётчик записей и обе ссылки «Завершённые встречи». В фильтрах встреч кнопка «Сбросить» имеет одинаковую высоту и нижний край с полями даты, в том числе при увеличенном тексте. Вкладка завершённых встреч остаётся доступной.

Звук личных и групповых сообщений проверен в Ubuntu ARM64 UTM через настоящий Desktop broker и renderer с отдельным локальным HTTPS-сервером. Запись системного аудиовыхода подтвердила четыре сигнала: до и после восстановления скрытого окна без пользовательского жеста. Проверены отключённые уведомления чата, общий выключатель звука, дубли и серии событий. В действующем профиле звук включён, громкость 100%, системный выход и поток MeetSpace не заглушены. В установленном пакете подтверждены обработчики и аудиофайл. Сообщённый разовый сбой не воспроизведён, production-код звука не менялся; добавлены проверки. Слышимость на динамиках Mac и конкретное уведомление реального сервера в этой проверке не подтверждены. [Подробности проверки звука](0.3.3-beta-audio.json).

Проверки: сборка TypeScript/React/Electron; 418 тестов Desktop пройдены, один платформенный тест пропущен. Визуальные проверки Electron: 80 снимков, светлая и тёмная темы, широкое и узкое окно, текст 150% для фильтров. Входящие кнопки звонка имеют геометрию соседних кнопок устройств; удалённые элементы записей отсутствуют.

Собраны восемь пакетов Windows/Linux для x64 и ARM64: Windows EXE, Linux DEB/RPM/AppImage. Содержимое, архитектура, размер, SHA-256/SHA-512 и происхождение проверены. Исходники: чистый commit `0a644a99960d473fcfb981cae80663ff6717580b`, 534 файла, SHA-256 `b85e6b75fff3b11f0b26595294dab66f1cf5ac24121c56f11fdc78d055a288ea`. Пакеты тестовые, без цифровой подписи; автообновление выключено. macOS и предыдущие выпуски сохранены.

В UTM обновлены и запущены Windows 11 ARM64 и Ubuntu ARM64, сохранены настройки и аккаунты. Проверены версия, файлы приложения, ярлыки и ограничение AppArmor. Экран UTM во время выпуска был неактивен; визуальная проверка выполнялась в общем Electron-интерфейсе. [Проверка UTM](0.3.3-beta-utm.json) · [Пакеты и исходники](0.3.3-beta-packages.json).

Все восемь пакетов повторно скачаны из опубликованного репозитория и проверены по размеру и SHA-256. На публичном лендинге подтверждены версия 0.3.3 beta, основные ссылки и каталог обеих архитектур. Android, macOS и остальные страницы сохранены. [Проверка публикации](0.3.3-beta-publication.json).
