# MeetSpace 0.3.4 beta

Исправлен звук уведомлений при работе с сервером, который не возвращает необязательное поле `summary` в настройках. Раньше из-за этого не применялись настройки всех категорий. Отсутствующее поле теперь отключает только уведомления об итогах; личные и групповые сообщения, приглашения, напоминания и записи работают независимо. Явные `summary: true` и `summary: false` учитываются; некорректные значения отклоняются.

Дополнительно проверены чтение и сохранение настроек в React: поле `summary` необязательное, при сохранении других параметров оно не добавляется, скрытый параметр `push` сохраняется. Проверены маршруты уведомлений о готовых итогах и ошибках подготовки, доступность вкладки итогов по возможностям сервера. Других подтверждённых проблем с `summary` не найдено. [Аудит и проверки](0.3.4-beta-summary-audit.json).

Проверки: 422 теста Desktop пройдены, один платформенный тест пропущен; 31 проверка frontend; 21 сценарий интерфейса Electron. Настоящий broker, renderer и аудиоплеер с ответом без `summary` подтвердили звук личных и групповых сообщений до и после восстановления скрытого окна, отключение звука и защиту от дублей. В Ubuntu UTM пользователь подтвердил слышимый сигнал входящего личного сообщения на первоначальной сборке исправления. [Проверка реального уведомления](0.3.4-beta-audio-fix.json).

Собраны восемь пакетов Windows/Linux для x64 и ARM64: Windows EXE, Linux DEB/RPM/AppImage. Исходники: чистый commit `fab3f40df7d5676581bccf1e6041b4469b46a6b0`, 534 файла, SHA-256 `3665f49f309a5f214c6450d765c170a1ee8d09a765307b47a7ff888f37e2f437`. Содержимое, архитектура, размер, SHA-256/SHA-512 и происхождение пакетов проверены. Пакеты тестовые, без цифровой подписи; автообновление выключено. [Пакеты и исходники](0.3.4-beta-packages.json).

Публикация на лендинге и обновление UTM выполняются; итоговые отчёты будут добавлены после проверки установленных приложений и публичных ссылок.
