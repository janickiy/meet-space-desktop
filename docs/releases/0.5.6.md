# MeetSpace Desktop 0.5.6

В разделе «Записи встреч» обновлены карточки видео, аудио и дорожек участников. Действия «Смотреть», «Слушать» и «Материалы» зависят от типа записи. Удаление требует прав и подтверждения.

Выпуск включает тестовые пакеты для x64 и ARM64. Для Windows доступен EXE, для Linux доступны DEB, RPM и AppImage. [Манифест пакетов](0.5.6-packages.json) · [Контрольные суммы](../../source/releases/0.5.6/SHA256SUMS) · [GitHub Releases](https://github.com/janickiy/meet-space-desktop/releases/tag/0.5.6).

Обновление с 0.5.5 и каталог с тестовыми записями проверены в Windows 11 ARM64 и Ubuntu 24.04 ARM64 в UTM.
