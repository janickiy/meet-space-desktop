# MeetSpace 0.7.1 — дизайн из «Архив 2.zip»

Дата проверки: 15 октября 2026 года. Обновлён общий React-интерфейс приложения; Windows-оболочка использует этот интерфейс через существующие main/preload и серверный транспорт.

## Основа и результат

Источник — предоставленный пользователем `Архив 2.zip`, SHA-256:
`0f022f09b5a00c20d44ad38453d14fe3b5af34e201ca14baf4a8dcb5e3bd1441`.
Архив использован как визуальный макет. Его демонстрационные данные и JavaScript не перенесены в приложение. Локально добавлен SVG-знак бренда; шрифт Inter поставляется с приложением.

| Раздел | Изменения |
| --- | --- |
| Оболочка | Светлая боковая панель, синяя палитра, тёмная тема, строка рабочего пространства, верхний поиск, реальные папки и аккаунт в навигации. Верхняя панель остаётся на месте при прокрутке. |
| Встречи | Три основных действия, группировка по дате, список/плитка, мини-календарь и блок активных встреч. Стартовый desktop-маршрут `/app` открывает встречи. |
| Чаты и группы | Список разговоров, аватары, сообщения, поле ввода, профили пользователей и групп; чат занимает доступную высоту окна. |
| Папки и записи | Карточки и списки, обновлённые пустые состояния и страницы содержимого; сохранены серверные действия и права доступа. |
| Календарь | Месячная сетка и навигация по датам с существующим запросом серверного диапазона. |
| Настройки | Диалог с навигацией и карточками, профиль, аккаунты, устройства, оформление и Windows-настройки. На узком экране сначала показывается список категорий. |
| Вход и первый запуск | Двухколоночное оформление, иллюстрация и формы существующей авторизации/выбора сервера. |
| Звонки | Тёмная сцена, панели управления и участники при демонстрации; обновлён вид предварительного подключения и личного звонка. |

Верхний поиск открывается кнопкой или Ctrl/Cmd+K: переход по разделам и фильтр **загруженного** списка встреч. Полнотекстовый поиск по всему серверу не добавлен. Переключение списка/плитки хранится в состоянии страницы. Элементы макета без реализованного серверного контракта не представлены как работающие функции.

Оконная рамка остаётся нативной. Нативные API, разрешения камеры/микрофона, выбор экрана, авторизация и жизненный цикл WebRTC не заменены кодом макета. Общие визуальные изменения также доступны веб-сборке; её сборка проверена.

## Проверки

Проверено на macOS ARM64 с Electron 44.7.1. UI-тесты используют production React, настоящий main/preload, одноразовые профили и локальные HTTPS-серверы с тестовыми данными. Проверка сертификатов включена. Рабочий сервер и пользовательские данные для этой проверки дизайна не изменялись.

| Проверка | Результат |
| --- | --- |
| Форматирование, TypeScript и web production build | PASS: `npm --prefix frontend run check` |
| Desktop production build | PASS: `npm --prefix desktop run build` |
| Desktop unit tests | PASS: 124/124 |
| Frontend desktop foundation / media / assets | PASS: 19/19 + 11/11 + 8/8; суммарно 162 теста с desktop suite |
| Визуальный сценарий | PASS: 35 снимков; обе темы, список/плитка, крупный текст 150%, окна шириной 1440, 1000 и 390 px |
| Shared React UI | PASS: вход, смена серверов и восстановление сессии, WSS reconnect, SSE, окно выбора источника, изоляция учётных данных |
| Product UI | PASS: чаты/группы, папки, календарь, записи, настройки, отключённый updater, ошибка недоступного сервера |
| Media permissions/lifecycle | PASS: синтетические устройства, отмена выбора источника, запрет чужого окна, события сна/возобновления, создание и остановка тестового видеотрека |
| Electron smoke | PASS: sandbox, изоляция Node, CSP, запрет внешних переходов и прямой сети, typed IPC, deep link |
| `git diff --check` | PASS |

В 35 визуальных состояниях нет горизонтального переполнения документа, отсутствующих изображений и необработанных ошибок окна. Снимки дополнительно просмотрены при корректировке оформления. Проверка активного звонка с двумя реальными участниками и новая Windows runtime-приёмка в этот проход не входили. Синтетический media-тест не подтверждает физические камеру, микрофон или Windows loopback.

Старый тест входа адаптирован к новому виду аккаунта: он проверяет уникальное имя вместо ранее отображавшегося email. Проверки изоляции сессий и приватных сообщений сохранены. Минимальный HTTPS fixture дополнен пустым ответом списка встреч для нового стартового экрана.

## Windows-сборки

Версия приложения — **0.7.1**, канал **MeetSpace Test**. Подпись издателя и канал обновлений пока не настроены, поэтому тестовые установщики не подписаны, автообновления отключены. Сборка на macOS и проверка извлечённого payload не означают успешную установку или runtime-приёмку на Windows.

Упаковка и проверка обоих установщиков завершены успешно. Из каждого `.exe` извлечён и проверен настоящий payload: x64 — PE `0x8664`, ARM64 — PE `0xaa64`; обе сборки содержат одинаковый `app.asar`. SHA-256 текущих исходников совпадает с обоими манифестами:
