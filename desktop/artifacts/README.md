# Рабочие результаты сборки

Готовые дистрибутивы перенесены в [source](../../source/README.md): `source/linux/<версия>/<DEB|RPM|AppImage>/<пакет>` и `source/windows/<версия>/<пакет>`.

Каталог `desktop/artifacts/` используется скриптами сборки для локальных результатов и промежуточных файлов; они не публикуются здесь повторно. Исходные отчёты и контрольные суммы перенесены вместе с пакетами.
